# Part 3 — Market Intelligence Dashboard
This folder contains the Tableau Public dashboard developed for Really Big Bank's Market Intelligence Analytics System.
## Dashboard Overview
The dashboard presents ASX 200 market activity and RBA Cash Rate Target movements to support market monitoring.
It includes:
- ASX 200 trading volume over 90 days
- ASX 200 and RBA cash rate comparison
- Red, Amber and Green (RAG) market monitoring indicator
- 20-day and 50-day moving averages
- Annualised volatility and maximum drawdown
## Files
- Market_Intelligence_Dashboard.twbx — Packaged Tableau workbook
- Dashboard_1.png — Dashboard overview and key indicators
- Dashboard_2.png — Trading volume and macro comparison
- Dashboard_3.png — Moving averages and volatility
## How to View
Download the .twbx file and open it using Tableau Desktop or Tableau Public Desktop Edition.
The screenshots provide an overview of the dashboard without requiring Tableau.
## Data Limitation
The trading volume value for 16 October 2026 was unavailable and has been left blank rather than estimated.
